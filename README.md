# TimeZonePicker

Interactive time zone converter using a world map.

## Usage

Open `index.html` in a web browser. First click on the map to choose the
source time zone, then click a second location to select the destination
time zone. Enter the time to convert in the input field (leave blank to use
the current time).

## Development

All required JavaScript libraries are included locally. A simple way to
preview the page is to run:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000/index.html` in your browser.
